> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Read `2026-09-04-wave-3-shared.md` first. Needs D3 merged (`SearchField`, `DateField`).

**Goal:** Every account you hold, grouped by kind with subtotals, shared ones apart and not diminished, archived ones behind a toggle; tap one to edit or archive it; *I counted, and it says this* reconciles it with one adjustment.

**Architecture:** `apps/mobile/src/accounts-screen.tsx` at route `(tabs)/accounts.tsx`? — **No:** S16 is reached from Today's balances and Settings, not a tab (S04 §2). Route `apps/mobile/app/accounts/index.tsx` (list), `accounts/[id].tsx` (editor), pushed as stack screens like `account/new`. Reads: `readAccounts` gains `groupId`, `ownership`, `archived`, `expectedBalance`, and an `{ includeArchived }` option (default false) — one query, one type. Writes exposed through session → port → controller per the shared rule: `updateAccount(id, version, patch)`, `archiveAccount(id, version)`, `reconcileAccount(draft)`, `createGroup(draft)`. The editor reuses `CreateAccountForm`'s fields as an `AccountEditor` (`packages/ui/src/accounts/account-editor.tsx`) taking the existing row and returning a patch (only changed fields — the executor refuses an empty patch); currency is shown, not editable (S16 §7). `ReconcileSheet` (`accounts/reconcile-sheet.tsx`) over `BottomSheet`. New `SharedGroup` composite (`accounts/shared-group.tsx`).

## Tasks

1. **Reads.** `LocalAccountSummary` + `groupId`, `ownership`, `archived`, `expectedBalance`; `readAccounts(db, { includeArchived })`. `readAccountsForNetWorth` stays. Snapshot `accounts` carries the new fields; `archivedAccounts` is a separate snapshot field loaded lazily when the toggle is on (a controller method `loadArchived()` → refresh). Tests.
2. **Writes on the port.** Four controller methods returning `{id} | {fieldErrors}`; refusals from the executors (stale version, shared+business, currency in patch) land as field errors. Tests with a scratch ledger.
3. **List.** `SearchField` over name; groups by `kind` (order per S16 §3: bank · cash · card · clearing · loans · investment · deposit · other) each with a subtotal header per currency (`money.sum` — never across currencies; a mixed-currency group shows one subtotal per currency); `BalanceRow` per account (`BIZ` tag; clearing's amber marker when `clearingBalance ≠ 0`); then `SharedGroup` with its own subtotal, same weight; then *Archived (n)* toggle revealing them muted. `EmptyState(first-run)` offering *Create account*. Tap → editor.
4. **Editor.** `AccountEditor` with `fieldErrors`; Save → `updateAccount` patch; *Archive* (danger button) → `archiveAccount` → back with a `Toast` (no undo — the shared plan says why). Opening balance/date edits show the S16 §5 confirm line (`accounts.openingConfirm`) above Save, not a dialog.
5. **Reconcile.** From the editor: *Reconcile…* opens `ReconcileSheet`: computed (from the snapshot, as of the chosen date via the same fold), observed (`AmountField`), `DateField` (default today), difference (live, `Amount` with `spend`/`income` ink), note, category (D4a's sheet if merged, else omitted — `categoryId` is optional). Save → `reconcileAccount`; zero difference is the executor's refusal shown as a field error on observed.
6. **Groups.** In the editor's group `Select`: *+ New group* → inline name → `createGroup` → selected. Rename/reorder/archive of groups wait for the desk table (DESK5) — say so.
7. **States, tests, stories, gate, PR** *"Every account, and what it says it holds"*. Stories: `Populated`, `WithShared`, `WithArchived`, `Empty`, `Editor`, `Reconcile`. Quote *Done when*.
