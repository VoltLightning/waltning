> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Read `2026-09-04-wave-4-shared.md` first. Base on `main` after E1, E2 and E3 merge.

**Goal:** The Debt tab is real: every person with money outstanding, their direction in words, a company's age; one person's full position across currencies with the two derived totals when a rate exists; and an editor that surfaces near-matches before a second record of the same person is created.

**Architecture:** New `packages/ui/src/counterparties/` (allowlist): `CounterpartyRow`, `DebtDirectionTag`, `AgeingBar`, `CounterpartyCard`, `BalanceLedger`, `CounterpartyPicker`, `CounterpartyForm` (D8's set; `SettleSheet` is E5's). `BalanceLedger` **owns the sign** — it takes E1's balances (already obligation-signed) and renders direction in words; no screen negates anything. Near-match: `packages/core/src/capture/trigrams.ts` (D1) — `jaccard` over folded names, threshold **0.3**, top three (S15 §9.1: loose, ranked), computed by `packages/client/src/counterparties/near-matches.ts` over the snapshot's counterparties minus recorded-distinct pairs. Three screens: `apps/mobile/src/debt-screen.tsx` (replaces the stub), `counterparty-detail-screen.tsx` (route `counterparty/[id]`), `counterparty-editor-screen.tsx` (routes `counterparty/new`, `counterparty/[id]/edit`). **Spec:** `screens/S12` §3 mobile, §4–§8 · `S13` §3–§8 · `S15` §3–§9 · `design-system/05` §5.5 · `SPEC.md` §6.6, §6.7 · O15 · P5 (direction in words) · `computations.md` §7.

## Tasks

1. **Components.** `DebtDirectionTag` (`owes you` / `you owe` / `settled`, text, `Tag` neutral); `AgeingBar` (four buckets, filled to the current one, label *{n} days · old* — never *overdue*); `CounterpartyRow` (monogram on a ramp tint hashed from the folded name, name, kind, `DebtDirectionTag`, net in **their** settlement currency through `<Amount>`, display-currency line beneath through `<FxAmount>` **only when E3's `readRate` answers** — else the line is absent, P1); `BalanceLedger` (one row per currency; rule line; `net in {settlement}` and `net in {display}` with `@ rate · date`, each absent without a rate); `CounterpartyCard`; `CounterpartyPicker` (over `BottomSheet`: `SearchField`, recent, list, *+ New*); `CounterpartyForm` (name, kind `SegmentControl`, settlement `Select` over currencies, contact, note; `MatchWarning` slot). Stories per state, both themes.
2. **S12.** Unallocated banner from E1's `unsettledClearing` naming the oldest transaction; `SegmentControl` All · They owe · You owe; the two direction totals per currency (never summed across people or currencies); rows sorted: companies by age desc, then by name. States: skeleton (totals last), `first-run` empty, *all settled* empty (a success), `ErrorState(recoverable)`. Tap → S13; no swipe.
3. **S13.** `CounterpartyCard` + `BalanceLedger`; `Settle` (primary, → E5's sheet; until E5 merges the button routes to a `Toast` *later* and the PR says so) and `Add transaction` (→ `/quick-add?counterpartyId=`; D4b's route parser gains the param); history through `searchTransactions({ counterpartyId })` (C4's filter gains `counterpartyId`) defaulting to `debt` rows with the toggle *debts only · {n} other rows* stating the hidden count; `AgeingBar` for companies. Empty = all settled, history kept.
4. **S15.** Create and edit; on name **blur**, `nearMatches` → `MatchWarning` with the candidate's balance (E1) and transaction count (`searchTransactions` total); *same person* → `mergeCounterparties` (edit mode: this record is the loser) or, in create mode, simply picks the existing one; *different* → `recordDistinctCounterparties`. Exact collision → the executor's refusal on the `name` field. Archive (edit mode) refused while a balance is open — the executor's message on a `Toast`. Unmerge is reachable from S13's overflow when a merge record names this id.
5. **Tab, routes, i18n.** `use-tab-bar-items` unchanged (debt is registered); three `Stack.Screen`s in `app/_layout.tsx`; keys in `en.ts` and `pl.ts`.
6. **Tests.** Render test per state per screen under react-native-web; `nearMatches` unit tests (`Ania` finds `Nina`; a recorded-distinct pair is skipped; three at most); the merge → unmerge round trip through the controller.
7. **Report.** Commit, push `feature/e4-debt-screens`; report PR *"Debt: who, how much, in what — and never netted across people"*.
