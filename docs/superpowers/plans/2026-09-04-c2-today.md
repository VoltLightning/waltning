# C2 · S04 Today — Implementation Plan (wave 3a)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Read `2026-09-04-wave-3-shared.md` first.

**Goal:** Today answers *where do I stand* with the real figures: mine and ours per currency in the hero, this month's spend and net, an unsettled-clearing banner when one exists, and five recent rows — with loading, error and empty states that are the design system's.

**Architecture:** `apps/mobile/src/today-screen.tsx` composes `Shell` (hero) + `GroundPanel` + the parts below; it fetches nothing itself beyond `usePhoneLedger`. Two new figures land on the device as **`money.ts` folds** in the style of A1 — `periodSpend(rows, period)` (`computations.md` §5 base figure: Σ signed of income/expense rows dated within the period, own accounts, business included; **no shared-boundary netting** — that is class S and needs `to_amount_pivot`, arc-full) and `unsettledClearing(balances)` (§8: every clearing account whose `clearingBalance ≠ 0`). Both are plain folds over rows the replica already reads, with a unit test each and a comment naming the SQL that E9 will differential-test them against. Two new components: `shell/period-header.tsx` (`‹ label ›` + *Today*, month granularity only in arc 1 — week/year/range are `PeriodPicker`'s, S25) and `shell/stat-tile.tsx` (figure + label + delta ink per §5.1).

**Spec:** `screens/S04-today.md` §3 mobile, §4, §5, §6, §7 · `computations.md` §3, §5, §8 · `design-system/09-state-matrix.md` (Today row) · `05-composites.md` §5.1 (`Shell`, `StatTile`, `DualTotal`, `Banner`).

**Board card closed:** *S04 · Today*.

**Branch:** `feature/c2-today` off `main`.

## Tasks

1. **Hero.** `DualTotal` from `readNetWorth` (A1) through `PhoneLedgerSnapshot.netWorth` — one `{mine, ours}` per currency; with one currency it is the hero pair, with more it stacks the way `CurrencyTotals` does today (reuse its "held separately" line). `FxStatusChip`/`CurrencyChip` are **not** rendered — no rates, no display currency (say so in a comment; the slots exist in `Shell`).
2. **Period row.** `PeriodHeader` (month, stepped with `addDays`-free month arithmetic on bare strings — a `shiftMonth(yyyyMm, ±1)` helper in `@waltning/core/date` with tests) + two `StatTile`s: *spent* and *net* for the shown month, from `periodSpend`. Period state lives in the screen (`useState`), not the store — S04 §7: only the lower row is period-scoped; the hero is as-of-now.
3. **Unsettled banner.** `Banner(warn)` when `unsettledClearing` is non-empty: `shell.unsettled` with the amount and the account, one action *Open* that navigates to the ledger filtered by that account (`/ledger?account=<id>` — C4 reads the param; until it merges, the route exists and shows the stub).
4. **Recent.** As today: five rows in a `Card`, *Show all →* to `/ledger`. A pending-write marker is not built (no outbox drain yet; note it).
5. **States.** Loading: `Skeleton(hero)` + five `Skeleton(row)` while `usePhoneLedger` reports no snapshot yet. Empty: `EmptyState(first-run)` as now. Error: `ErrorState(recoverable)` in the panel when the controller's snapshot carries an error (add `error?: string` to the snapshot if absent, set from the refresh's catch — one line), the hero keeping its last figure. Offline: not modelled on the phone-alone ledger; omit and say so.
6. **Gate and PR.** Screen tests per state; stories for `PeriodHeader` and `StatTile`; the screen's own story if `apps/mobile` has a story runner, otherwise the render tests carry it. PR *"Today says where you stand"*; quote *Done when*; name what is deliberately absent (chips, voice row, scan, pending markers, shared-boundary netting).
